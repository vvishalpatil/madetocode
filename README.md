# Made to Code

Vishal Patil's portfolio site, built with React + TypeScript + Vite + Tailwind CSS.
Longer-term this may grow into a broader platform.

## Development

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — type-check and build for production
- `npm run preview` — preview the production build
- `npm run lint` — lint the codebase
